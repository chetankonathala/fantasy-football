Replace the three `NotImplementedError` stubs in `src/fantasy/engine.py` with full implementations. Add these private helper functions:

**Helper: `_redistribute(weights: dict[str, float], absent: set[str]) -> dict[str, float]`**
- Remove keys in `absent` from weights dict
- Redistribute removed weight proportionally to remaining keys so total = 1.0
- If all keys absent, return empty dict

**Helper: `_matchup_sub_score(rank: Optional[int]) -> Optional[float]`**
- rank 1 (easiest) -> 100.0, rank 32 (toughest) -> 0.0
- Formula: `round(100.0 * (32 - rank) / 31, 2)`
- None -> None

**Helper: `_avg_usage(weekly: list[Optional[float]]) -> Optional[float]`**
- Average of non-None values; None if all are None

**Helper: `_count_data_weeks(weekly: list[Optional[float]]) -> int`**
- Count non-None entries in list

**Helper: `_apply_injury_veto(injury_status: Optional[str]) -> Optional[str]`**
- If status in INJURY_VETO ("Out", "Doubtful"): return `f"Hard SIT: {injury_status} — player ruled out"`
- Else: return None

**Reason builder helpers (template strings per CONTEXT.md decisions):**
- `_summary_reason(verdict: Verdict, primary_signal: str) -> str`: `f"Strong {verdict.value}: {primary_signal}"` for START; `f"{verdict.value}: {primary_signal}"` for FLEX/SIT
- `_matchup_reason(rank: int, position: str) -> str`: `f"Favorable matchup: #{rank} defense vs {position}"` if rank <= 10; `f"Neutral matchup: #{rank} defense vs {position}"` if rank <= 20; `f"Tough matchup: #{rank} defense vs {position}"` if rank > 20
- `_usage_reason(avg_share: float, position: str, weeks: int) -> str`: label = "snap share" for QB, "target share" for WR/TE, "carry share" for RB. `f"Strong usage: {pct}% {label} (L{weeks}W)"` if avg >= 0.20; `f"Low usage: {pct}% {label} (L{weeks}W)"` otherwise. pct = round(avg_share * 100).
- `_projected_reason(pts: float) -> str`: `f"Projected: {pts:.1f} fantasy points"`
- `_low_confidence_reason(weeks: int) -> str`: `f"Low confidence: only {weeks} week(s) of data available"`
- `_pad_reasons(reasons: list[str], min_count: int = 3, max_count: int = 5) -> list[str]`: If < min_count, append generic padding notes. If > max_count, truncate. Padding strings: `"Limited signal set — matchup is primary factor"`, `"No additional risk factors identified"`.

**`_score_skill(signals: SkillSignals, fmt: ScoringFormat) -> Recommendation`:**
1. Check injury veto first: if `_apply_injury_veto(signals.injury_status)` returns a reason string, return Recommendation(verdict=SIT, score=0.0, reasons=[veto_reason, ...padded to 3], low_confidence=False, scoring_format=fmt)
2. Compute sub-scores:
   - matchup_sub = `_matchup_sub_score(signals.matchup_rank)`
   - usage_avg = `_avg_usage(signals.snap_pct_l4w)` — use snap_pct as the primary usage metric for all skill positions
   - For WR/TE: also compute target_avg = `_avg_usage(signals.usage_share_l4w)` and blend: `usage_sub = (snap_avg * 0.4 + target_avg * 0.6) * 100` if both present. For RB: blend carry_share similarly. For QB: usage_sub = snap_avg * 100 (snap only).
   - projected_sub = `min(100.0, (signals.projected_points / PROJECTED_POINTS_CEILING) * 100)` if not None, else None
   - confidence_sub = `_count_data_weeks(signals.snap_pct_l4w) / 4.0 * 100`
3. Determine absent signals and redistribute weights:
   - absent = set of keys where sub-score is None
   - weights = `_redistribute(SKILL_WEIGHTS.copy(), absent)`
4. Apply PPR format modifier (per CONTEXT.md):
   - For WR/TE: add FORMAT_MODIFIERS[fmt]["usage_delta"] to usage weight, add FORMAT_MODIFIERS[fmt]["projected_delta"] to projected weight
   - For QB/RB: no usage_delta applied (PPR does not affect QB or RB carry share)
   - FORMAT_MODIFIERS: PPR = {"usage_delta": +0.05, "projected_delta": +0.05}, HALF_PPR = {"usage_delta": +0.025, "projected_delta": +0.025}, STANDARD = {"usage_delta": 0.0, "projected_delta": 0.0}
   - After applying deltas, re-normalize weights to sum to 1.0
5. Compute composite: sum of (weight * sub_score) for each present signal
6. Apply injury penalty: if signals.injury_status == "Questionable", subtract INJURY_PENALTY_PTS (15.0) from composite
7. Clamp: `composite = min(100.0, max(0.0, composite))`
8. Determine verdict: >= START_THRESHOLD -> START, >= SIT_THRESHOLD -> FLEX, else -> SIT
9. Determine low_confidence: `_count_data_weeks(signals.snap_pct_l4w) < 4`
10. Build reasons array:
    - Determine primary signal (highest weighted sub-score contributor)
    - reasons[0] = `_summary_reason(verdict, primary_signal_description)`
    - Append matchup, usage, projected, confidence reasons in priority order (skip None signals)
    - If low_confidence, append `_low_confidence_reason(weeks_count)`
    - `_pad_reasons(reasons)` to enforce 3-5 bounds
11. Return Recommendation(verdict, composite, reasons, low_confidence, fmt)

**`_score_kicker(signals: KickerSignals, fmt: ScoringFormat) -> Recommendation`:**
1. matchup_sub = `_matchup_sub_score(signals.matchup_rank)` if not None, else 50.0 (neutral default)
2. vegas_sub: if signals.vegas_implied_team_total is not None, normalize (e.g., total/30*100 clamped), else None
3. Composite = matchup_sub if vegas is None, else weighted average (0.6 matchup + 0.4 vegas)
4. Clamp to [0, 100]
5. Verdict from thresholds
6. reasons = [summary, matchup_reason, padding...] — pad to minimum 3 using `"Vegas total unavailable — matchup is sole factor"`, `"K scoring is matchup-dependent"`
7. Return Recommendation(verdict, composite, reasons, low_confidence=False, scoring_format=fmt)

**`_score_dst(signals: DSTSignals, fmt: ScoringFormat) -> Recommendation`:**
1. opponent_sub = `_matchup_sub_score(signals.opponent_offense_rank)` if not None, else 50.0
2. implied_sub: if signals.opponent_implied_points is not None, normalize, else None
3. Composite = opponent_sub if implied is None, else weighted average (0.6 opponent + 0.4 implied)
4. Clamp to [0, 100]
5. Verdict from thresholds
6. reasons = [summary, opponent_reason, padding...] — pad to minimum 3 using `"Opponent implied points unavailable — opponent rank is sole factor"`, `"DST scoring is opponent-dependent"`
7. Return Recommendation(verdict, composite, reasons, low_confidence=False, scoring_format=fmt)
