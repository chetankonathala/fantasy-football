  <action>
Replace the placeholder `SearchBar.tsx` with the full implementation. This is a `"use client"` component.

**Imports:**
```typescript
"use client";
import { useState, useEffect, useRef, useCallback } from "react";
import { useRouter } from "next/navigation";
import { useDebounce } from "use-debounce";
```

**Types:**
```typescript
interface PlayerResult {
  id: number;
  full_name: string;
  position: string;
  team: string;
}
```

**State:**
- `query: string` — raw input value
- `debouncedQuery` — from `useDebounce(query, 300)`
- `results: PlayerResult[]` — search results
- `isOpen: boolean` — dropdown visibility
- `isLoading: boolean` — fetch in progress
- `activeIndex: number` — keyboard navigation index (-1 = none)

**Fetch effect** (triggers on `debouncedQuery` change):
- If `debouncedQuery.length < 2`: clear results, close dropdown, return
- Set isLoading true
- `fetch(`http://localhost:8000/search?q=${encodeURIComponent(debouncedQuery)}`)`
- On success: setResults(data), setIsOpen(true), setIsLoading(false)
- On error: setResults([]), setIsLoading(false)

**Selection handler:**
- `router.push(`/player/${result.id}`)` — navigates to player page
- Clear query, close dropdown

**Keyboard handler** on input `onKeyDown`:
- ArrowDown: increment activeIndex (clamp to results.length - 1)
- ArrowUp: decrement activeIndex (clamp to 0)
- Enter: if activeIndex >= 0, select that result
- Escape: close dropdown, reset activeIndex

**Click outside** handler:
- useRef on the wrapper div
- useEffect with mousedown listener that checks `!ref.current.contains(e.target)` → close dropdown

**Render structure:**
```
<div ref={wrapperRef} className="relative">
  <input
    type="text"
    value={query}
    onChange={(e) => { setQuery(e.target.value); setActiveIndex(-1); }}
    onKeyDown={handleKeyDown}
    onFocus={() => results.length > 0 && setIsOpen(true)}
    placeholder="Search players..."
    aria-label="Search players"
    role="combobox"
    aria-expanded={isOpen}
    aria-controls="search-listbox"
    className="w-full bg-[#111827] border border-[#A5ACAF] rounded-md px-4 py-2 text-white
               placeholder-[#A5ACAF] focus:border-[#004C54] focus:border-2 focus:outline-none"
  />
  {isLoading && <Spinner inside input trailing position />}
  {isOpen && (
    <ul id="search-listbox" role="listbox" className="absolute z-50 w-full mt-1 bg-[#111827]
        rounded-md shadow-lg overflow-hidden">
      {results.length === 0 ? (
        <li className="px-4 py-3 text-[#A5ACAF] text-sm">
          No players found
          <span className="block text-xs mt-1">Try a different name or check the spelling.</span>
        </li>
      ) : (
        results.map((r, i) => (
          <li
            key={r.id}
            role="option"
            aria-selected={i === activeIndex}
            onClick={() => selectPlayer(r)}
            onMouseEnter={() => setActiveIndex(i)}
            className={`px-4 min-h-[44px] flex items-center cursor-pointer text-white
              ${i === activeIndex ? "bg-[#004C54]/50" : "hover:bg-[#004C54]/30"}`}
          >
            {r.full_name} <span className="text-[#A5ACAF] ml-2">— {r.position}, {r.team}</span>
          </li>
        ))
      )}
    </ul>
  )}
</div>
```

**Loading spinner:** Use a simple 16px animated spinner (CSS `animate-spin` on a circular border element) positioned absolutely inside the input's trailing edge. Color: `#A5ACAF` (silver).

Ensure the dropdown only shows when `isOpen` is true AND (results.length > 0 OR (debouncedQuery.length >= 2 AND !isLoading)). This covers the "No players found" case after a completed search with no results.
